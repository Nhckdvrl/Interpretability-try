## Stage 1 — one-sentence natural-object gate

Before discussing mechanism, ask:

> Can another NLP/ML researcher understand why the question matters without hearing a benchmark name, an SAE, a layer, or an activation method?

If no -> kill or reformulate before deeper search.

Examples of valid shapes:

- `Does the model know that two identical-looking objects can still be different individual objects?`
- `When reference is unresolved, does the model keep alternatives alive or prematurely pick one?`

Examples of invalid shapes:

- `Which layer encodes benchmark feature X?`
- `Can an SAE separate label A/B?`

---

## Stage 2 — paper-scale sanity, not theory-complexity gate

Check benchmark-removal, natural-object, normal scope, story invariance, and venue-scale comparators.

Do **not** require every candidate to arrive with three mature mechanism theories.

A simple new object can be paper-scale if it is broad, surprising/important, separable from obvious confounds, and causally usable.

---

## Stage 3 — strongest-neighbor novelty attack: N0 / N1 / N2

This is currently the highest-mortality stage.

Search in three passes:

### N0 — object ownership

Has any prior neural/LLM paper already asked the same scientific question, even if its **title** sounds unrelated?

Read methods, factor definitions, appendices, tables and discussion, not only abstracts/headlines.

### N1 — causal occupancy

Has prior work already performed the decisive factorization/intervention?

### N2 — delta width

After stating the strongest prior in one sentence, is our remaining contribution a **new scientific/model object**, or merely:

```text
old behavior/representation
-> modern open model
-> stronger probe/SAE/patching/steering
```

The latter is normally kill.

### Current lesson

**Object ownership, not title ownership.**

039 died because its scientific object was already present inside papers whose headlines emphasized cultural fidelity/topic modeling. Ownership-vs-possession died because an RLVR paper encoded owner and possessor as separate world-state variables. Authority-vs-expertise died because the authority-mechanism paper explicitly discussed competence as a separate construction.

## Stage 4 — route-aware substrate / existence gate

This is where the old search became too strict. The rule now depends on route.

### Route A — mother omitted axis

Need natural axis B, natural cross-cells, row-level auditable substrate, and a mother recipe that can be legitimately extended.

### Route B — established anomaly + mechanism debate

Need an already established exact behavior on analyzable modern models and genuinely competing computations.

### Route C — simple natural object first

**Do not require an already published exact Llama/Qwen phenotype as a universal hard gate.**

Legal anchors include:

- prior public behavior/released outputs;
- a deterministic externally established semantic/cognitive axis;
- a natural human substrate with labels/manipulations that do not depend on LLM judgment;
- strong prior evidence that analyzable open models can engage the underlying domain.

A cheap reproduction/capability check may occur during execution as long as:

1. the question is already frozen;
2. a null still answers that same question;
3. we do not search prompts/subsets until a story appears;
4. GPU results cannot redefine the object.

Thus:

```text
no exact modern-open published phenotype
!= automatic KILL
```

But also:

```text
no prior object/substrate + run GPU to see whether anything interesting happens
= behavior lottery -> KILL
```

## Stage 5 — confound identifiability

Before PASS, write the strongest superficial explanation and show a design path that separates it.

Examples:

- numerical identity: definite article / `another`, lexical repetition, recency, ordinary coreference, type similarity;
- unresolved reference: ambiguity detection versus candidate-specific representation;
- metaphor route: syntax/`like` token versus comparison/categorization computation.

If the proposed measurement cannot identify the headline object, the question may survive but GPU authorization pauses (036 is the current example).

---

## Stage 6 — minimal causal-use contract

For Route C/A, we only need **one clear falsifiable causal-use question**, not a pre-written cognitive monograph.

Typical form:

> `A representation of X is decodable; does changing X while holding the obvious confounds fixed actually alter an X-sensitive downstream decision?`

Required:

- negative/random/shuffled control;
- no best-layer cherry-picking as the primary result;
- intervention must be tied to the natural object, not only output tokens;
- passive decodability alone cannot carry the paper.

# Why finding topics currently feels unusually hard

The difficulty is real, but it is not because natural questions are rare.

## 1. 2025–2026 literature already moved from behavior to hidden states very quickly

Many seemingly fresh simple axes already have probes, steering or activation interventions in current work: tool necessity, authority hierarchy, self-authorship, false consensus, ordinal geometry, ambiguity uncertainty, deception-vs-error, etc.

Therefore `nobody has done patching` is now a very weak novelty signal.

## 2. Older neural-model papers can also own the object

We cannot search only modern LLM titles. Examples:

- habitual/episodic properties were already predicted from contextual representations years ago;
- de re/de dicto was already a neural-model object;
- relative/absolute adjective semantics was already an LM formal-semantic probe;
- same-token vs different-token-same-type event representations were already tested in 2021 RNN hidden states.

This is why promising candidates often survive the first search and die one layer deeper.

## 3. Strong human science and strong LLM novelty are different gates

A beautiful human 2×2 proves the scientific object is real, but does not prove LLM novelty. Conversely, no LLM paper does not automatically make a topic good if we would need to manufacture synthetic data and gamble on whether behavior exists.

## 4. We are deliberately refusing method-only novelty

If the true contribution is just:

```text
prior knows object X behaviorally
-> we do X with SAE/patching
```

we kill it. This removes many easy-looking candidates but is necessary for ACL/EMNLP/NAACL Main-scale novelty.

## 5. We are also refusing to protect the target count

039 demonstrated why this matters: a superficially strong, clean candidate can still die after registration if deeper object ownership appears.

The target `5` is a desired register size, not a quota.

Therefore the project must establish an abstract identity relation beyond that event-specific precedent, with cross-domain/cross-surface generality and causal use.

The search should now try to **save or kill this exact candidate**, not abandon it merely because a published modern-open phenotype is missing.
