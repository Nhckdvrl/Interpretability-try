# 现象筛选要求

版本：2026-08-28
状态：`FROZEN v2 — v1 保留于 Git 历史；本版增加模型调用前的 N0/D0 授权门`

## 一句话目标

寻找一个**普通人能立即理解、在不同模型家族和尺寸上真实存在、不会因能力增强自然消失、具有清楚结构与因果解释空间，并且尚未被最近工作完整覆盖**的反直觉现象。

## A. 问题本身

1. **自然。** 不依赖任意符号、复杂规则、特殊标签或长篇 prompt 才能成立。
2. **一句话能说清。** 应能写成“模型明明 A，却仍然 B”，并让非本方向研究者立即知道哪里奇怪。
3. **母问题足够大。** 指向知识、信念、实体、现实性、因果、记忆、推理、交流、行动或社会认知等基本问题，而不是某个小 benchmark 的局部技巧。
4. **有反直觉性。** 不只是“模型会犯错”，而是能力 A 完好、行为 B 却崩溃，或者出现 cliff、U-shape、sign reversal、path dependence 等结构。
5. **不是 prompt 设计产物。** 换成简短客观提示、自然问法或自由生成后，核心性质仍应存在；不能靠主观/客观系统提示制造结论。
6. **不是为了证明它而拼装。** 优先从人类已有问题、真实任务或公开数据的自然结构中发现；合成数据只允许实现一个先验清楚的原理。

## B. 一般性与规模生存

7. **五家族面板，三家族通过。** 默认家族为 Qwen、Gemma、Phi、Llama、Mistral；核心现象至少在其中 `3/5` 个独立家族同方向成立。
8. **至少三个尺寸。** 至少一个家族必须包含三个参数尺寸并呈现同一核心性质，现象不能只存在于单个 checkpoint 或一对尺寸。
9. **具有规模生存理由。** 即使暂时无法运行最大模型，也必须说明为何它来自目标冲突、计算分解、训练偏好或接口之间的 dissociation，而非单纯能力不足。
10. **强模型杀伤测试。** 在投入机制研究前，用可得的较强模型检查是否几乎消失；若消失，除非存在清楚且重要的 scaling transition，否则停止。
11. **有能力基线。** 模型在匹配 control 上确实理解任务、相关概念和输出格式。
12. **允许诚实边界。** 个别不重要家族不成立不必降级整个题，但必须报告；不得隐藏关键反例或用挑模型制造“普遍”。

## C. 行为证据质量

13. **不设统一效应硬门槛。** 效应大小必须结合任务噪声、paired consistency、统计不确定性和结构性判断。大幅 accuracy change 很有价值，但稳定的 dissociation、cliff、U-shape、sign reversal 或规律性错误落点也可以独立构成强现象。
14. **选择性。** 目标 manipulation 的效应显著大于长度、格式、措辞、顺序、标签和一般难度控制。
15. **关系有效。** invariance、equivariance、monotonicity 或 reversibility 的规范预期必须能独立证明，而不是研究者主观认为答案“不该变”。
16. **对照闭环。** 原任务、目标条件、能力 control、nuisance control 和反向/对称条件共同排除最简单解释。
17. **看配对轨迹。** 保存单样本前后变化、错误落点和恢复轨迹，不能只看总体 accuracy。
18. **评分可靠。** 优先 deterministic scorer；自由生成要保存原文并做语义审计，选择题要平衡标签与位置。
19. **可复现。** 数据容易获得或按公开原理容易构造，脚本、模型参数、prompt、原始输出和随机种子完整保存。
20. **构造数据的实质性要求。** 允许构造，但不能用过度简单、结论导向的模板硬造现象。构造必须建立在对母问题、规范关系、现实实例和潜在混淆的充分理解上；生成后必须随机抽样人工检查自然性、关系有效性、难度与标签，并把抽样记录存档。

## D. 新颖性与题目尺度

21. **母现象可以已有。** 不要求与所有文献完全无关。
22. **独特性质必须未被做完。** decisive contrast、结构 signature、scaling dissociation 或因果问题至少有一项是现有母现象不具备的。
23. **不得被更大工作完整包含。** 如果最近论文已经覆盖同一行为、跨模型、控制、机制与缓解，则淘汰；若只覆盖母现象，必须把我们的增量写成一句不可替换的区别。
24. **模型调用前完成 N0 精确审计。** 必须检索 exact phenotype、近义术语、老问题、母现象包含关系、同期 arXiv/ACL/EMNLP/NAACL/OpenReview 及引用链；不能把决定性检索推迟到异常出现后。
25. **区分未发现与不存在。** 文档只能写“截至某日未检索到”，不能把搜索结果写成绝对优先权证明。
26. **符合主会尺度。** 题目应支持一个完整故事：稳定行为、结构性质、机制解释、跨设置验证和由机制导出的预测或方法，而非只有一个 benchmark drop。
    具体尺度参照 [`CONFERENCE_SCALE_AUDIT.md`](CONFERENCE_SCALE_AUDIT.md)：问题可以窄，但证据链必须厚；不靠堆积互不相关任务制造“大题”。
27. **生成者与审计者分离。** 候选提出者不能独自签署 N0；独立审计者必须主动寻找 collision、换皮包含和规模消失证据。
28. **行为发现与机制续作分线。** exact behavior 已知时 discovery 线直接 KILL；只有用户明确授权才能转 mechanism-followup，且不得宣称新行为。
29. **Smoke 后做 N1。** 用真实错误目的地、曲线、scale law 与 controls 二次检索；N1 未通过，不扩家族/尺寸。

## E. 可解释性与方法口

30. **至少两个竞争机制。** 两种解释必须对层、位置、表征、路径、干预或 scaling 做出不同预测。
31. **适合 matched comparison。** 最好只有一个自然因素改变，能进行 probe、activation patching、causal tracing 或 interchange。
32. **行为不是机制的同义改写。** “因为模型更关注 X”不算机制，必须能定位和因果干预。
33. **机制可能跨模型。** 不要求完全相同参数，但要有可比较的 computation-level hypothesis。
34. **留有方法口。** 如果机制 A 成立，应自然推出与机制 B 不同的修复；修复不能只是增加一句提示或要求更长 CoT。
35. **发现阶段只做小规模 feasibility。** 在行为、一般性和新颖性过门前，可以运行少量 probe、patch 或表示检查来确认“有方法口”，但不得跨大量层、头、模型和数据铺开机制实验。

## F. 搜索方法要求

36. **现象是搜索输出，不是输入。** 不先决定研究某个 bias，再寻找能证明它的样本。
37. **先母问题，再选轴。** 从基本心智概念或老问题出发，找理论上应保持不变、按规则变化或可逆的自然自由度。
38. **优先能力解离。** 搜索 `A 会但 B 不会`、`A 随规模增强而 B 不增强`、`表征存在但行为不用`，而非泛化的低准确率。
39. **大量准备 source distributions。** 覆盖语言、知识、数学、逻辑、记忆、时序、空间、因果、社会推理、RAG、工具使用、代码和真实交互数据。
40. **允许大胆假设，但必须先审计再证伪。** N0/D0 通过后才用小模型扫轴；出现异常后先读 raw cases 并完成 N1，再扩家族与尺寸。
41. **失败也建档。** 记录为何自然性不足、为何随规模消失、为何依赖接口、为何撞车，防止重复投入。

## “确定好的现象”的定义

只有以下四项都确定，才可进入 confirmed/promoted 主清单：

1. **行为确定：** 现象本身经过可靠评分、原始案例检查和关键 controls；
2. **一般性确定：** 达到五家族中至少三家族，并含至少一个三尺寸序列；
3. **新颖性确定：** N0 与 N1 均完成，确认独特性质未被已有工作完整覆盖；
4. **审计独立：** 至少一位非候选提出者签署 novelty verdict，注册表保存证据。

只满足行为真实性的候选仍值得存档，但必须标记为 `MINE` 或 `HOLD`，不得称为“确定好的现象”。
