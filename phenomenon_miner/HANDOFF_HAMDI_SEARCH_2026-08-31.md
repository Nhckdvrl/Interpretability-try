## What this conversation actually accomplished

The search standard was tightened from `five promising ideas` to `five authoritative PASS-REGISTER topics that can directly enter experiments`. The first five paper-scale ideas were therefore re-audited instead of promoted, and **all five died**:

1. explicit vs implicit memory systems — **KILL-NOVELTY**: ACL 2026 ImplicitMemBench already frames implicit behavior as non-reducible to explicit storage/retrieval and suggests distinct mechanisms; causal double dissociation would be mother mechanization.
2. prototype vs exemplar categorization — **KILL-NOVELTY**: EACL 2026 Best Paper already occupies abstraction-vs-exemplar language learning; prototype/exemplar + MI is not a safe N2 delta.
3. source independence / false corroboration — **KILL-NOVELTY**: 2026 `Beyond Memory Majority` already owns shared-origin/correlated evidence being counted as independent and proposes provenance-aware correction.
4. model-based vs model-free decision control — **KILL-NOVELTY / KILL-BEHAVIOR**: the LLM-specific axis is already directly studied, and two-step behavior is not uniquely diagnostic enough to freeze an experiment-ready S0.
5. event-boundary memory organization — **KILL-BEHAVIOR**: LLM event segmentation exists, but ordinary-comprehension boundary-driven memory restructuring lacks a sufficiently established modern open-model phenotype.

This was the key correction: **paper-scale is necessary but not enough; registration requires novelty width + executable substrate + established phenotype/legitimate Route A + frozen causal contract.**
