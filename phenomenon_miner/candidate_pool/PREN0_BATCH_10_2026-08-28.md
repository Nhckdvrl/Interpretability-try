# 1. Publicness–Coordination Dissociation

**canonical reference：** [`SEC-01`](06_SOCIAL_EVIDENCE_COLLECTIVE.md)

```yaml
stage: N0-AUDITING
validation_authorized: false
priority: A
naturalness: N3
collision_risk: HIGH
```

**一句话矛盾。** 模型明明知道 Alice、Bob、Carol 每个人都收到了同一条消息，也知道消息是分别私发还是公开宣布，却预测两种情况下会产生相同的协调行为。

**日常例子。** 老师分别私信每名学生“考试取消”，与在全班群公开宣布“考试取消”，一阶知识可以相同；但公开事件额外让大家知道别人也看见了公告，从而改变是否需要再次确认、是否默认别人也会按公告行动等协调行为。

**为什么可能是论文题，而非普通 ToM 错误。** 目标不是再测一阶/二阶 false belief accuracy，而是固定每个人的一阶知识完全相同，只改变 `private delivery ↔ public event`，检查模型是否拥有一个能真正进入 coordination policy 的 publicness/common-knowledge operator。

**自然数据锚点。** FANToM、Reflect、多方会议/群聊中原生 public/private communication；原则性 matched pair 只能作为 causal isolation，不能替代自然数据。

**只有出现以下 signature 才晋级。**
- public/private channel 本身识别正确；
- 每个人的一阶 knowledge 在两条件均正确；
- 只有需要 coordination / higher-order action 的 readout 把 public 与 separate-private 压平、倒置或出现人数相关 cliff；
- 若只是普通二阶 ToM 不会，KILL。

**竞争机制。**
1. 没有独立 `public-event` representation，只给每个人分别写 belief slot；
2. publicness 已形成并可解码，但没有进行 higher-order closure；
3. closure 已存在，但 coordination reader 只聚合一阶 beliefs。

**最近工作与可辩护空位。** FANToM、common-ground 工作与 EMNLP 2025 DEL-ToM 已经覆盖动态 belief update、public/private communication 等宽母题。只有 `matched first-order knowledge + publicness-specific coordination/action dissociation` 才可能保留。

**最便宜证伪。** 先做全文级 N0，重点查 public announcement / common knowledge / coordination / dynamic epistemic logic；若已有工作已经做同一 matched contrast 与 downstream coordination，直接 KILL。

# 2. First-Negative-Evidence Harm

**canonical reference：** [`../../phenomenon_miner/phenomena/002_first_negative_evidence_harm.md`](../phenomena/002_first_negative_evidence_harm.md)

```yaml
stage: N0-AUDITING
validation_authorized: false
priority: A
naturalness: N3
collision_risk: MEDIUM
behavior_anchor: existing cross-family smoke signal
```

**一句话矛盾。** 模型本来答对一道选择题；现在只增加一条真实且确定的“选项 C 已被独立验证为错误”信息，反而把它推错；继续增加第二、第三条同类正确排除信息后又恢复。

**为什么可能是论文题。** 不是“排除法难”，而是信息增量出现结构性的 **non-monotone / threshold-like curve**：少量正确负证据有害，更多负证据反而有益。

**自然数据锚点。** 当前已有 GPQA Diamond wave-1；后续若 N0 通过，再外部确认到 ARC/MMLU 等公开 MCQA，且保留原任务与官方 gold。

**关键 decisive contrast。** ACL 2025 *Exclusion of Thought* 已表明直接删除 distractor 往往单调帮助；ACL 2025 *Llama See, Llama Do* 又提示仅在 context 中重新出现某个 option token 就可能提升它的 logit。因此本卡必须区分：

```text
semantic negative evidence: “C 已被确认错误”
mention-only control:      “C 已被检查/再次提到”
positive/salience control: “请特别考虑 C”
physical deletion:         直接移除 C
```

**只有出现以下 signature 才晋级。**
- baseline-correct → one-negative-wrong 在多家族稳定出现；
- 错误不只是流向被再次 mention 的 option；
- mention-only 无法解释 negative semantics 的额外伤害；
- `negative_1 → negative_2/3` 呈稳定恢复或 cliff；
- 若 effect 完全等同 contextual entrainment，KILL standalone novelty。

**竞争机制。** negative-evidence gate 触发异常 option-set renormalization；negative statement 中的 option token 与 elimination signal 走竞争路径；latent answer retrieval 被一次局部 verification 重新初始化，而多次 elimination 后进入另一种 reduced-set computation。

**最便宜证伪。** N0 先精读 EoT / contextual entrainment / PoE 文献；随后若获授权，第一实验不是扩数据，而是做 mention-only matched control。

# 3. Existential Witness Collapse

**canonical reference：** [`RVC-04`](08_REASONING_VERIFICATION_COMPOSITION.md)

```yaml
stage: N0-AUDITING
validation_authorized: false
priority: A
naturalness: N3
collision_risk: MEDIUM
```

**一句话矛盾。** 模型明明知道“有人会日语”和“有人懂税务”可以由两个不同的人满足，组合任务时却偷偷假定存在一个人两样都会。

**日常例子。** 团队里有一名会 CUDA 的工程师，也有一名会日语的工程师，不代表一定存在一名同时会 CUDA 和日语的人。

**规范关系。** `∃x P(x)` 与 `∃y Q(y)` 不推出 `∃z(P(z)∧Q(z))`。关键不是测试量词定义，而是测试 **anonymous witness identity 是否在 downstream composition 中被错误 fuse**。

**自然数据锚点。** FOLIO / LogicBench 作为规范逻辑锚；自然 staffing、room assignment、schedule/constraint problems 作为外部 setting。原则性模板只用于 binding isolation。

**只有出现以下 signature 才晋级。**
- 模型能正确解释两个 existential witness 不必同一；
- 对每个局部属性与候选人/对象的判断正确；
- 最终组合或计划却稳定产生 same-witness fusion；
- 错误 destination 必须是一个可预测的 fused entity，而非随机答错。

**竞争机制。** 两个 discourse referent 在 representation formation 时就 merge；referents 中层分开但 composition readout 复用同一 salient slot；binding 正确但 planner 为满足复合目标错误执行 entity join。

**最近工作与可辩护空位。** quantifier scope、variable binding、syllogistic reasoning 都已拥挤；只有 `scope/identity knowledge intact → independent witnesses fused in downstream composition` 才可能不是普通 quantifier error。

**最便宜证伪。** N0 exact search `existential witness / anonymous witness / witness identity / variable binding / existential conjunction / discourse referent fusion`；若已有完整 phenotype+mechanism，KILL。

# 4. Part-List Cue Suppression

```yaml
provisional_batch_id: P10-04
stage: IDEA
validation_authorized: false
priority: A
naturalness: N3
source_status: HUB
collision_risk: MEDIUM
why_not_a_rename: unresolved; must distinguish from generic list truncation, repetition, and retrieval saturation
```

**一句话矛盾。** 模型本来能列出 A/B/C/D/E；现在先告诉它“A、B 已确认是正确答案，请继续给其他答案”，它反而更难想起 C/D/E。

**日常原型。** 人类记忆研究中成熟的 *part-list cuing impairment*：提供记忆集合中的一部分作为 cue，有时会压制对其余项目的自由回忆。候选不是要求模型复刻人类 bias，而是借这个老问题定义一个天然搜索轴：**正确子集信息是否反而破坏剩余集合的检索。**

**自然数据锚点。** QAMPARI 的多答案问题最适合作主数据：每题天然有多个人工核验答案。可外部确认到其他多答案 QA / entity enumeration 数据。

**发现轴。**
- baseline：只给问题，自由列答案；
- part-list：给 1/2/3 个已知 gold，再要求列“其他”答案；
- matched non-gold / semantically unrelated cue；
- cue 与剩余答案同 cluster / 异 cluster；
- 只评分 **uncued gold recall**，避免已提供答案把总 recall 人工抬高。

**只有出现以下 signature 才晋级。**
- 被 cue 的答案与未 cue gold 单独 recognition 均高；
- part-list 条件选择性降低 uncued recall；
- 不是单纯 output budget、EOS、列表长度或重复抑制造成；
- cue 数量或语义 cluster 产生稳定结构，而非平均小跌。

**规模生存理由。** 更强模型拥有更多可回忆知识，也可能形成更强的语义 search trajectory；“知识存在”与“如何遍历答案空间”接受不同训练信号，因此规模增长不保证消失。

**竞争机制。**
1. retrieval inhibition：cue 激活一个语义簇并压制竞争簇；
2. strategy disruption：外部 cue 打断模型原本的 enumeration/search plan；
3. context-reset：已给答案使模型错误估计任务接近完成并提前切换到 stopping state。

**最近工作与可辩护空位。** 多答案 QA、knowledge boundary、fallback/repetition 工作很多，但截至 2026-08-28，以 `part-list cuing / part-list cueing / retrieval-induced forgetting + LLM / language model` 为核心检索式，当前初筛未找到完整覆盖“gold subset supplied → uncued gold recall selectively drops + mechanism”的工作。该表述只是 PRE-N0 搜索记录，不是 novelty 结论。

**最便宜证伪。** 先全文 N0；若通过，再用 30 个 QAMPARI 样本、固定最大输出长度，比较 baseline vs 1/2/3 gold cues。若未 cue recall 不降或仅由 EOS/长度解释，立即 KILL。

# 5. Equivalent-Quantity Decision Split

```yaml
provisional_batch_id: P10-05
stage: IDEA
validation_authorized: false
priority: A
naturalness: N3
source_status: HUB
collision_risk: HIGH
why_not_a_rename: must prove conversion/comparison are intact; otherwise this is only numeracy/unit conversion
```

**一句话矛盾。** 模型明确知道 `1900 g = 1.9 kg`，也能正确判断两者都低于 `2 kg`；但在同一个筛选或推荐任务中，仅仅改变单位表示就作出不同决定。

**日常例子。** 用户要求“行李必须低于 2 kg”。同一商品写成 `1.9 kg` 或 `1900 g` 不应改变是否合格。

**规范关系。** 对可精确换算的物理量，unit conversion 是一个确定的 representation invariance；真实 quantity 与阈值关系保持不变，downstream eligibility/action 应保持不变。

**自然数据锚点。** DeepQuant 类商品 quantity constraint、FinQA/TAT-QA 中自然数值条件、公开商品/物流规格任务；正式 D0 必须选择 license 清楚且 conversion 定义无歧义的数据。

**发现轴。** `1.9 kg ↔ 1900 g`、`2 m ↔ 200 cm`、`0.5 L ↔ 500 mL`；加入只换 unit spelling、不改变 numeral magnitude 的 control，以及同 numeral 不同真实 quantity 的反向 control。

**只有出现以下 signature 才晋级。**
- conversion 正确；
- equality/ordering 正确；
- threshold classification 正确；
- 只有最终 choice/action 对等价表示不 invariant；
- 若前面任一步错，归入普通 numeracy，KILL standalone。

**竞争机制。** canonical quantity representation 根本没有进入 decision path；canonical value 已形成，但 late decision reader 仍直接读取 surface numeral magnitude；unit token 与 numeral magnitude 形成 competing heuristic path。

**最近工作与可辩护空位。** NUMCoT、numeracy NLI、DeepQuant 等已经覆盖 conversion/comparison difficulty。只有 `semantic equivalence + threshold relation intact / downstream decision split` 才有独立空间。

**最便宜证伪。** N0 后先用 20–30 个无歧义 quantity threshold case；若 action 与 comparison 完全同步，KILL。

# 6. Generation–Reception Trace Asymmetry

```yaml
provisional_batch_id: P10-06
stage: IDEA
validation_authorized: false
priority: B
naturalness: N2
source_status: HUB
collision_risk: HIGH
why_not_a_rename: unresolved; must beat self-conditioning, role/source effects, and generic repetition
```

**一句话矛盾。** 完全相同且已确认正确的中间事实，模型若刚才“自己推出来/说出来”，稍后比直接从上下文读到同一句事实更容易记住或使用；或者出现稳定的反方向差异。

**日常原型.** 人类记忆中的 *generation effect* 指自行生成的信息常比被动阅读的信息留下更强记忆痕迹。这里不预设模型必须复制人类方向，而是问：**内容相同、正确性相同，形成路径是否让后续 trace strength 不同。**

**自然数据锚点。** HotpotQA / MuSiQue 等 multi-hop QA 的 gold bridge fact：一种条件由模型先生成并被 deterministic verifier 确认，另一条件由外部上下文以完全相同文字提供；最终问题与可用事实匹配。

**发现轴.** self-generated verified fact vs externally supplied identical fact；控制 role token、重复次数、token distance、是否再次 echo；不要把“模型自己的猜测”当成更可信证据。

**只有出现以下 signature 才晋级。**
- 两条件最终可见事实内容严格 matched；
- source/provenance 能正确报告；
- 后续 recall/use 出现跨任务稳定差异；
- 差异不能由 recency、重复、assistant/user role 或 self-consistency 解释。

**竞争机制.** generation pathway 形成更强 residual trace；事实 representation 等强，但 self-generated token 获得特殊 source/self tag 并在 downstream reader 中被加权；差异只是 role-conditioned attention，而非 memory formation。

**最近工作与可辩护空位.** self-conditioning、自我一致性、self-correction 与生成式学习都很拥挤。初步 exact search 未找到 ACL/EMNLP/NAACL 对“identical verified fact: generated vs read → later trace/use asymmetry”的完整机制研究，但本卡 collision 风险高，N0 很可能会被杀。

**最便宜证伪.** 先做 N0；若不能设计出 role/repetition 完全 matched 的合同，直接 KILL，不造大数据。

# 7. Redundant-Constraint Distortion

```yaml
provisional_batch_id: P10-07
stage: IDEA
validation_authorized: false
priority: A
naturalness: N3
source_status: HUB
collision_risk: MEDIUM-HIGH
why_not_a_rename: must distinguish from ordinary constraint neglect and repeated-instruction weighting
```

**一句话矛盾。** 模型明明知道新加的一条限制完全由原有限制推出、不会改变任何可行方案，却因为加入这条冗余约束而改变最终计划或选择。

**日常例子。** 原要求是“酒店价格低于 20,000 日元”；再加一句“而且必须低于 30,000 日元”不会排除任何新酒店。若模型因此改选另一家酒店，决策依赖的是约束表面而不是可行集。

**规范关系.** 若 `C1 ⇒ C2`，则 feasible set `F(C1) = F(C1 ∧ C2)`。在其他偏好完全相同时，增加逻辑冗余 constraint 不应改变选择。

**自然数据锚点.** TravelPlanner / NaturalPlan / AR-LSAT / 公开 constraint-satisfaction planning 数据；只从原规则中生成可形式证明的 entailed constraint，gold 由 deterministic checker 冻结。

**发现轴.** nonredundant hard constraint、strictly weaker redundant constraint、paraphrastic duplicate、irrelevant constraint；先问 entailment/redundancy，再做 candidate feasibility 与 final selection。

**只有出现以下 signature 才晋级.**
- redundancy/entailment 判断正确；
- candidate×constraint feasibility matrix 不变且基本正确；
- 最终 choice/plan 只因冗余约束出现而系统改变；
- 错误最好跟 constraint count、位置或被重复强调的属性呈结构 interaction。

**竞争机制.** 模型未 canonicalize feasible set，而是逐 constraint 累加启发式权重；feasible set 已正确形成，但 utility/choice reader 把重复 constraint 当额外偏好强度；late attention salience 覆盖已计算的 feasibility state。

**最近工作与可辩护空位.** constraint-following、constraint-aware planning 已很拥挤；ACL 2026 *Check Your Work* 甚至讨论 trivial/redundant checklist items 会稀释训练 reward，但这不是同一 behavioral invariance。正式 N0 必须检查是否已有 `redundant-but-entailed constraint changes final choice` 的直接工作。

**最便宜证伪.** 先做 20 个 2–4 candidate 的短问题，deterministic verifier 证明 feasible set 完全相同；若 final choice invariant 或只有 feasibility 本身错，KILL。

# 8. Packed–Unpacked Event Splitting

```yaml
provisional_batch_id: P10-08
stage: IDEA
validation_authorized: false
priority: A
naturalness: N3
source_status: REMOTE
collision_risk: MEDIUM
why_not_a_rename: must distinguish from generic framing/paraphrase and ordinary probability incoherence
```

**一句话矛盾。** 模型能证明“E”与“E1 或 E2 或 E3”是同一个事件、三个子事件互斥且穷尽，却在把事件展开成三个分支以后给它更高的总概率或决策权重。

**日常原型.** 人类判断研究的 *support theory / unpacking effect / event-splitting effect*：同一事件被显式拆成多个具体子事件时，主观支持度可能上升。这里借它定义一个非常干净的 extensionality invariant，而不是预设 LLM 一定像人类。

**日常例子.** “航班因技术原因延误”与“因发动机、航电或其他技术原因延误”（若这三个分支被定义为互斥且穷尽）指向同一个总事件；总概率或相同 payoff 的决策价值不应因为写成三行而改变。

**自然数据锚点.** ForecastQA / 公开 forecasting questions、体育/天气等拥有可验证互斥 outcome taxonomy 的公开历史数据；D0 必须确保 partition 真正 exhaustive/disjoint，而不是研究者主观拆分。

**发现轴.** packed category vs 2/3/4-way exhaustive unpacking；等长 paraphrase control；非穷尽 unpacking control；frequency judgment vs probability/decision judgment。

**只有出现以下 signature 才晋级.**
- equivalence、mutual exclusivity、exhaustiveness 均判断正确；
- packed 与 unpacked 的总 probability / decision weight 仍系统不同；
- effect 随 branch count 呈结构规律，而非任意 wording sensitivity；
- 将子事件重新 pack 后应出现 reversibility test。

**竞争机制.** explicit branches分别触发 retrieval/support accumulation 后被重复计权；semantic event representation已等价，但 probability reader按显式 branch nodes 求和；纯 surface framing path 与 extensional event state 竞争。

**最近工作与可辩护空位.** conjunction/disjunction fallacy、概率一致性工作已经很多；2026 也有 GPT-5 probability reasoning 的广泛行为研究。初步 exact search未找到顶会对 `recognized exhaustive unpacking → probability/decision weight inflation` 的 LLM mechanism study。N0 必须围绕 `support theory / unpacking / partition dependence / event splitting + LLM` 全文核查。

**最便宜证伪.** 先构造不超过 20 个由公开 taxonomy 可形式验证的 packed/unpacked pair；若 equivalence 本身不稳，或只在主观 probability 语言里出现不可复现噪声，KILL。

# 9. Part–Whole Double Counting

```yaml
provisional_batch_id: P10-09
stage: IDEA
validation_authorized: false
priority: A
naturalness: N3
source_status: HUB
collision_risk: HIGH
why_not_a_rename: unresolved; likely adjacent to F6 local-to-global reduction and numerical table reasoning
```

**一句话矛盾.** 模型明明知道“许可证 60 万”已经包含在“软件总预算 100 万”里面，计算总预算时却仍把 100+60 算成 160 万。

**日常例子.** 报表写“营销费用 200 万，其中线上广告 80 万”。`其中` 是 part-of relation，不是两个并列账项。

**为什么可能是论文题.** 目标不是 arithmetic error，而是 **mereology/hierarchy recognition intact → aggregation operator nevertheless treats parent and child as disjoint addends**。错误 destination 极清楚，就是 overlap double count。

**自然数据锚点.** FinQA、TAT-QA、HiTab、MultiHiertt 等金融/层级表格 QA；正式 D0 只保留 hierarchy 与 subtotal provenance 能从原表明确验证的样本。

**发现轴.** parent total + included child、两个真正独立 sibling、parent+excluded extra item、flattened canonical total；分别测 inclusion relation、局部数字、应加/不应加与最终 aggregation。

**只有出现以下 signature 才晋级.**
- `child ⊂ parent` 关系回答正确；
- parent/child 数值读取正确；
- 同样的独立 sibling addition 正常；
- final aggregation 选择性产生 `parent + included child` double count；
- 错误应随 hierarchy relation，而非表格位置或数字 salience 移动。

**竞争机制.** hierarchy edge可解码但 reducer只对所有 salient numeric nodes做 sum；parent node和child node在表示阶段未标记 overlap；结构表示正确但 answer planner使用“列出数字→全部相加”的 learned algorithm。

**最近工作与可辩护空位.** table reasoning、financial QA 与 part-whole semantic competence 都已有工作；仓库 F6 也已明确覆盖 local→global reducer 错误。本卡只有找到一个稳定、跨表格的 `inclusion-recognition intact / overlap double-count` signature，并证明其机制不是 generic F6 的简单实例，才值得 standalone；否则应 ROUTE 到 F6 而不是新题。

**最便宜证伪.** 先做 mother-inclusion N0；若已有 hierarchical-table paper 已直接分析 subtotal/part double counting 或 F6 足以完整解释且无独特机制预测，直接 ROUTE/KILL。

# 10. Confidence-Conditioned Correction Relapse

```yaml
provisional_batch_id: P10-10
stage: IDEA
validation_authorized: false
priority: B
naturalness: N2
source_status: HUB
collision_risk: HIGH
why_not_a_rename: must distinguish from self-correction, knowledge conflict, belief perseverance, and generic calibration
```

**一句话矛盾.** 两个错误都收到同样明确、权威、已被模型接受的纠正；原先模型越自信的错误，过几轮后越容易重新恢复成旧答案，而不是保持已经承认的新答案。

**日常原型.** 人类记忆研究存在 *hypercorrection effect*：高置信错误在明确反馈后有时反而更容易被纠正。这里不把“是否复制人类 hypercorrection”当目标，而用它提供一个成熟的 surprise/confidence→memory-update 竞争轴；我们真正寻找的是 **initial confidence 是否在 correction 已被接受后继续控制长期更新强度**。

**自然数据锚点.** TriviaQA / Natural Questions 等公开事实 QA；先用模型自身 pre-feedback answer probability/稳定性定义 confidence，再给相同格式、来自 gold 的 authoritative correction，插入若干无关自然问题后 retest。

**发现轴.** initial confidence quantile × identical correction；immediate acceptance vs delayed retention；external correction vs mere contradiction；高频 parametric fact vs低频 fact。

**只有出现以下 signature 才晋级.**
- correction 当下被正确复述并明确接受；
- immediate post-feedback answer 已更新；
- delayed relapse 对 initial confidence 呈稳定、非平凡曲线；
- 错误 destination 精确回到原先旧答案，而非随机遗忘；
- 同样 token distance/干扰长度 controls 后仍存在。

**竞争机制.** 强 parametric attractor 在 context correction 消退后重新主导；prediction-error/surprise gate决定 correction trace 写入强度；显式 answer state更新了，但底层 factual representation未更新，later query重新读取旧 parametric path。

**最近工作与可辩护空位.** ACL 2025 *Confidence v.s. Critique*、self-correction、context-vs-parametric knowledge、knowledge editing/feedback learning 都高度邻近。因此本卡当前 HIGH collision；只有 `correction accepted now → later relapse specifically conditioned on prior confidence` 未被做完，才可能留下。

**最便宜证伪.** 先全文 N0；若最近论文已按 initial confidence 分层研究 external-feedback retention，KILL。若没有，再用公开 gold QA 做极小 delayed-retest pilot，而不是训练或大规模 API。
