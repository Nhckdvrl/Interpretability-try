1. **scientific object 仍独立**：不是 strongest neighbor 的一个 benchmark/domain/readout 切片；

## 3. 当前 19 题的 D0 落地路径与下一非模型动作

下面只记录“为什么今天还能继续”，不是提前宣称 PASS。

### 3.1 Alias Entrainment Transfer — S

**Natural source**：Wikidata entity IDs + language-specific labels/aliases；结构化 Wikidata 数据为 CC0。Wikidata 的 alias guideline 明确把 common alternative names、acronyms、abbreviations、translations/transliterations 作为 aliases，而不是允许研究者随便编缩写。

**Recipe**：只收 `(entity, alias_A, alias_B)`，要求两个 alias 都是公开记录的 common name；target `alias_B` 在 prompt 中 byte/token normalized absent；再用 exact-target mention、same-entity descriptor、semantic-related non-alias、unrelated matched context 做四路 control。

**必须补**：20 对人工检查 alias conventionality + ambiguity；按 alias type/frequency 分层，不能把自己造的缩写混入主效应。

### 3.2 Task-Switch TR/TL Desynchronization — S

**Natural source**：EMNLP 2024 `llm-task-switch` 官方 MIT repo + ICLR 2026 `Localizing_TR_TL` 官方 MIT repo。

**Recipe**：锁定两边共同可表达为 ICL classification 的 public tasks；在 task identity 与 label mapping 可独立诊断的子集中做 switch/remap factorial。

**必须补**：20 switch pairs 确认不是 context length/label-token artifact；full appendix/code refresh 确认没人已把 TR/TL decomposition 用于 task-switch interference。

### 3.3 GeoTemporal Binding Bottleneck — S

**Natural source**：GeoTemp 官方 repo，公开 code/data，CC BY 4.0；母数据本身覆盖城市/国家/timezone 与 joint questions。

**Recipe**：从同一 joint item 派生 geography-only、offset/arithmetic-only、joint 三视图；gold 全部由 GeoTemp metadata/timezone arithmetic 程序验证。

**必须补**：随机 20 joint failures 的 source/transform audit，冻结 component gating 不改变问题语义。

### 3.4 Causal Retrieval Schedule — S

**Natural source**：母论文 Needle/multi-hop setup + HotpotQA-style support chains。

**Recipe**：先选具有同一第一跳、可控第二跳目的地的 matched chains；pre-retrieval 时刻只干预 plan-predictive subspace，观察 future head schedule 与 support-span destination 是否同步改向。

**必须补**：20 matched chains 的 content-preservation audit；N1 code/appendix 确认母论文没有 pre-activation causal plan intervention。

### 3.5 Correlation → Agreement — S

**Natural source**：公开真实 method-comparison / paired measurement datasets。

**Recipe**：从真实 paired observations 计算 Pearson/Spearman 与 Bland–Altman bias/LoA、CCC/absolute ICC；再用 `y' = y + c` 等严格 transformation 构造 `correlation invariant / agreement changed` 对照，gold 由本地统计计算确定。

**必须补**：至少两个应用域各 10+ 真实 units，避免变成医学统计小题；20-case 人工检查最终“interchangeable”语言是否有明确 gold。

### 3.6 Subgroup-Significance → Interaction Promotion — S

**Natural source**：公开 RCT subgroup-reporting datasets；BMJ Open 2024 的 subgroup reporting study 数据/代码公开于 GitHub 且文章 CC BY 4.0；既有 meta-research 还提供 subgroup estimates、interaction tests 与 authors' claims。

**Recipe**：只保留能取得 subgroup-specific estimates/p-values 与 interaction test（或可从 CI 独立重算）的 trial；先验收 model 读对 interaction，再看 downstream 是否仍以 `sig/not-sig` 差异宣称 heterogeneity。

**必须补**：20 trial audit，确保 interaction test 与 claim 对的是同一 endpoint/subgroup/timepoint。

### 3.7 Stock–Flow Correlation Intrusion — S

**Natural source**：经典 Department Store/Bathtub/queue/inventory stock-flow tasks 与公开实验材料；人类文献已把错误归纳为 correlation heuristic。

**Recipe**：所有条件由 `S_{t+1}=S_t+I_t-O_t` 本地 oracle；必须 capability-gate net flow sign 与公式理解，错误只允许发生在 stock trajectory/peak/turning point。

**必须补**：20 个自然 scenario/trajectory，至少覆盖 inventory/queue/reservoir 三类，避免只复制一个 Department Store 图。

### 3.8 Predicate-Revision Eager-Flag Staleness — A

**Source path**：母论文官方 released filtering tasks + Wikidata CC0 structured entities 构造自然 entity lists/attributes。

**Recipe**：`Q-before`, `Q-after`, `P→P`, `P→Q`；P/Q 必须让 00/01/10/11 四种 membership 都出现，gold 程序化。

**Blocker**：先做 20 个 Wikidata-based natural list audits，证明不是玩具 list/predicate prompt 才出现的题。

### 3.9 Training-Recency Conflict Arbitration — A

**Source path**：`Fresh in memory` 母训练 recipe + Wikidata CC0 relation triples 作为 natural fact anchor。

**Blocker**：冻结 exposure-balanced conflicting fact construction，并证明两条事实在 isolation 都 retained；否则只是 forgetting/weight strength，不是 recency-axis causal use。

### 3.10 Resolved-Ambiguity Neuron Persistence — A

**Source path**：AmbigQA/AmbigNQ 提供真实 ambiguous questions、disambiguated rewrites/evidence articles。

**Blocker**：先解决 dataset reuse/license chain，并人工审计 20 个 `same exact question + context uniquely resolves one interpretation` 的 cases；不能把 extra-context length/attention dilution当 feature collapse。

### 3.11 Dead-Branch Residue after Invalidation — A

**Natural source**：ALFWorld（MIT）提供 3,553 train games、PDDL initial states、TextWorld game files 与 admissible commands。

**Recipe**：从一个 state 中选两条 valid branches；执行最小 state-changing action 后用 PDDL/admissible-command oracle 确认其中一条 branch closed、另一条仍 valid。

**Blocker**：20 branch closures 必须是 goal-preserving minimal update；若 residue 只等于旧文本 recency，ROUTE 到 stale-state family。

### 3.12 Mixed-Status Event Attraction — A

**Natural source**：MAVEN-FACT 公开 repo，112,276 event factuality annotations，并保留 evidence/arguments/relations。

**Recipe**：筛同一局部结构中 factuality status 不同的 event pairs；单独与组合条件共享原文，错误必须是 directional attraction，而不是普通 context parsing failure。

**Blocker**：锁定 dataset/license inheritance 与 20 pair audit；确认 pair relation/distance 可独立分层。

### 3.13 Habitual → Episode Actualization — A

**Source path**：UDS/Decomp genericity 数据区分 episodic、habitual、generic predicates；使用自然句子而不是研究者自写“usually”模板。

**Recipe**：只选 gold 为 habitual/generic 且明确不蕴含指定 occurrence 的 source sentence；程序化加最小 dated downstream query/timeline interface，检测是否凭空创建 episode token。

**Blocker**：20 样本证明 derived interface 不引入“默认发生一次”的语用含义；否则只是构造 artifact。

### 3.14 Noninferiority → Equivalence Collapse — A

**Natural source**：CliniFact 提供 1,970 clinical claim-evidence pairs / 992 trials，并包含 NI、equivalence、NI-or-equivalence test types；可沿 NCT/PMID 回到 ClinicalTrials.gov/PubMed 原始 trial。CliniFact repo 为 MIT。

**Recipe**：CliniFact 只做 locator，不能把其 `Non-Inferiority or Equivalence` 合并标签当 gold；主集只选原试验明确是 one-sided NI、margin/CI 可冻结且 source 本身没有“equivalent” spin 的 cases。

**Blocker**：20 true-NI trials 人工审计；N1 专查 MedLitSpin/clinical-claim work 是否已有 neutral true-NI + recognition-intact downstream equivalence promotion。

### 3.15 Surrogate → Clinical-Outcome Promotion — HOLD

**Natural source**：FDA downloadable Surrogate Endpoint Table + ClinicalTrials.gov/PubMed。FDA 明确 surrogate 不是 direct measurement of clinical benefit，并区分 validated 与 reasonably-likely/context-dependent use。

**Blocker**：必须先成功链接 >=20 `trial outcome → exact FDA surrogate/context-of-use status → target clinical outcome` 的 cases。不能把所有 surrogate 一律标成“不允许 clinical claim”；如果 context 本身已支持 direct benefit，case 必须排除。

### 3.16 Harmless-Error → Remedy Collapse — HOLD

**Natural source**：COLD Cases（8.3M US legal decisions，CC0）+ 可核对的 appellate disposition metadata。

**Blocker**：dry-run 必须找到 >=20 opinions 同时明确写出 `error exists`、`harmless/no prejudice` 与 disposition/remedy；若只能人工主观判断 prejudice，不能过 D0 feasibility。

### 3.17 Competing-Event → Censoring Collapse — B

**Natural source**：公开 survival/competing-risk teaching/clinical datasets；event time/status 为真实 structured outcomes，CIF/KM/risk-set 可本地计算。

**Blocker**：先做一个 >=20 unit 的自然 source package，并确认 strong-model 能力基线理解 competing event/censoring；否则会退化成 specialized capability test。

### 3.18 Dissent → Holding Role Swap — HOLD

**Natural source**：COLD Cases（CC0）把 majority/dissent authors/text 和 metadata 放在同一 case record；SCDB 可提供 Supreme Court votes/disposition/direction 等结构。

**Blocker**：必须找到可程序化/外部冻结的 **holding proposition**，而不是让研究者自己摘要 holding。若 20-case audit 仍依赖主观法学摘要，本题 HOLD-DATA-GOLD。

### 3.19 Action-Boundary State Routing — HOLD-N1

**Natural source**：母论文六个 agent benchmark/EBP correction pairs；可先锁 ALFWorld 子集降低 license heterogeneity。

**Blocker**：母论文已经在行为层直接解释为 elicitation gap，并声称 latent boundary perception。下一步必须先 full-text + appendix + code 确认作者没有 representation probing/patching/latent-state causal analysis；若已有，本题 KILL-COLLISION，不允许换措辞继续。

## 4. 本轮明确移出的 5 个非历史题

### First-Negative-Evidence Harm — KILL / ROUTE

`Anchored Confabulation` 已证明 partial confirmed evidence 能非单调增加 confident-wrong，且跨多家族/有 causal injection。First-Negative 剩余 novelty 只能靠“negative subtraction 而非 positive anchor”守边界，但 natural D0 实际上需要在 MCQ prompt 里人为告诉模型某个 option false，再与 mention/deletion 控制拼 factorial。这个研究对象太依赖测试协议，不够像独立自然现象。

### Burden-Placement Null-Case Reversal — KILL-DISCOVERY-DATA

burden doctrine 本身重要且自然；问题在于 decisive experiment 要 **同一 unresolved evidence 下只交换 burden holder**。现实案件中 burden allocation 是法律规则的一部分，不是自然可自由交换的变量。若把它人工改写，就同时改了适用法律世界。没有找到可批量、自然、hard-gold 的 matched units，因此按 v4 在选题阶段就停止。

### Short-Circuit Side-Effect Leakage — ROUTE TO CoRE

CoRE 已把 `correct final output + wrong intermediate execution state` 作为核心 Superficial Execution phenotype，并在多种实现/状态 probes 上系统验证。short-circuit 的 value/effect 双通道很漂亮，但更像 CoRE 下一个可解释 subtype，而不是足够宽的新 main-paper mother question。

### SQL UNKNOWN Interface Collapse — ROUTE TO Squirrel-Semantic

Squirrel-Semantic 的 taxonomy 已显式包含多类 NULL/3VL semantic bugs，包括 `NOT(a=b)` vs `a!=b`、NULL comparisons、NULL join keys 等。WHERE/CHECK 对 UNKNOWN 的 designated-value 区别仍可作为诊断 item，但不值得单独占一个 LLM interpretability topic。

### Synonym-Saturation Escape in Semantic BM25 — ROUTE OUT OF CURRENT SCOPE

这个问题在 IR mechanistic interpretability 里是合理的，但 mother object 是 cross-encoder relevance model，不是本仓库当前要找的 LLM/agent natural behavior；剩余 question 又只是在已定位 BM25-like circuit 内追 saturation counting unit。保留在 Git history/领域 inventory 即可，不进入 current 19。
