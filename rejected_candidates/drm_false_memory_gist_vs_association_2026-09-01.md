# DRM semantic false memory: gist traces vs associative activation

Date: 2026-09-01  
Verdict: **KILL-BEHAVIOR**

## Semantic aliases

- DRM critical-lure false memory in LLMs
- gist-based vs spreading-association false recall
- fuzzy-trace vs associative activation
- semantic lure false recognition

## Natural question

When a system falsely remembers an unpresented but semantically central item, is the error driven by a gist-level semantic representation or by associative activation spreading from the studied items?

This is a mature memory-science debate. The Deese–Roediger–McDermott paradigm and fuzzy-trace/associative-activation theories long predate LLMs and supply theory-diagnostic manipulations.

## Decisive kill evidence

Repeated searches for DRM / Deese-Roediger-McDermott / critical lure / semantic false recognition together with Llama, Qwen, transformers, and large language models did not identify a published modern-open-model phenotype in which:

1. a model studies a DRM-style associated-word list;
2. the critical lure is not presented;
3. later recall/recognition falsely accepts the critical lure at elevated rates;
4. the effect is established on multiple relevant modern open families with auditable row-level stimuli.

Current `AI false memory` literature instead overwhelmingly studies LLMs/chatbots *implanting false memories in human users*, which is a different scientific object.

Continuing would require building a DRM protocol and running models to discover whether the core phenomenon exists. That violates the current behavior-lottery prohibition.

## Nearest-neighbor warning

Do not substitute hallucination, misinformation acceptance, RAG errors, semantic completion, or AI-induced human false memory for canonical DRM false recognition. Those do not establish the required memory phenomenon.

## Resurrection condition

Reopen only if public work establishes critical-lure false recall/recognition on >=2 modern open model families with exact DRM-style item lists and scoring, while the gist-vs-associative mechanism remains causally unoccupied in LLM MI.
