# Rejection — Intentional vs Accidental Action

Date: 2026-09-01  
Verdict: **KILL-NOVELTY**

## Natural question

Does a model distinguish an outcome someone intended from the same outcome happening accidentally or merely as a side effect?

## Semantic aliases

- intentionality
- intended vs accidental outcome
- Knobe effect
- side-effect intentionality
- intent attribution

## Why it looked promising

Intentionality is a simple everyday property that can be separated from the physical outcome itself. Matched scenarios can hold consequence constant while changing intention or foreknowledge.

## Decisive kill evidence

2025 mechanistic work `Analysing Moral Bias in Finetuned LLMs through Mechanistic Interpretability` directly studies the Knobe side-effect effect in multiple open LLMs using layer-level interventions/patching. Other LLM intentionality work independently evaluates side-effect intent attribution.

This already occupies both the behavioral intentionality object and a mechanistic-intervention version of it.

## Strongest-neighbor warning

Do not revive as intent direction, accidental-vs-deliberate steering, side-effect intentionality circuit, or moral-intent patching.

## Death code

`F2 / N0-N1-N2 — direct behavioral and mechanistic object ownership.`

## Resurrection condition

Only a distinct natural mental-state property not reducible to intentionality attribution could reopen the area.
