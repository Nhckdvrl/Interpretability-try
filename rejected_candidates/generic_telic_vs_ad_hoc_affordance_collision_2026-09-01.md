# Rejection — Canonical/Telic Function vs Context-Induced Ad-Hoc Affordance

Date: 2026-09-01  
Verdict: **KILL-NOVELTY**

## Natural question

Does a language model distinguish what an object is conventionally **for** from what it can merely be **used for in the current situation**? A funnel is for pouring, but in a special context it can be used to hang a coat.

## Semantic aliases

- telic function vs ad-hoc affordance
- canonical use vs alternative use
- conventional purpose vs situational affordance
- lexical function vs contextual use

## Why it looked promising

Human psycholinguistic work provides an excellent natural crossover: lexically stored generic/telic affordances can conflict with context-induced unconventional affordances, and the context can reverse which action is expected. This seemed like a clean Route-A/Route-C semantic distinction rather than generic object identity.

## Decisive kill evidence

The object is already substantially occupied in LLM behavior:

- CogALex 2024 `What GPT-4 Knows about Aspectual Coercion: Focused on “Begin the Book”` directly tests default lexical/telic interpretations versus contextually preferred coerced interpretations.
- 2026 constructional-coercion work extends coercion behavior across modern LLM architectures.
- 2026 `Affordance-driven symbol network construction via large language models` explicitly reports object-alone action tendencies and **context-specific affordances** in GPT-4, Llama-3 8B, and Gemma-3 4B; environmental and multi-object contexts systematically shift the retrieved object actions.
- Contemporary Alternative Uses / tool-repurposing work further establishes canonical-versus-unconventional object-use behavior across current models.

Under the post-039 rule, this already owns the scientific distinction well enough that a hidden-state direction or causal steering study would mainly replace the method with stronger MI rather than introduce a new model object.

## Strongest-neighbor warning

Do not revive as telic-role vector, canonical-vs-alternative-use direction, affordance steering, context-induced function patching, or `for X` versus `can be used as X` probing.

## Death code

`F2 / N0-N2 — conventional/default versus context-induced object-use semantics already established in LLM behavior; remaining delta is primarily mechanism.`

## Resurrection condition

Only a distinct object-function property whose scientific interpretation is not equivalent to lexical/default function versus contextual affordance could reopen this family.
