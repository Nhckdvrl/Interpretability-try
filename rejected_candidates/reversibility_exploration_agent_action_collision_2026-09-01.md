# Rejection — Reversibility / Exploration Status of Agent Actions

Date: 2026-09-01  
Verdict: **KILL-NOVELTY**

## Natural question

Before acting, does an agent distinguish information-seeking/revisable actions from actions that irreversibly change the world?

## Semantic aliases

- reversible vs irreversible action
- epistemic/information-seeking action
- exploration vs exploitation
- act vs abstain
- safe-to-try vs committing action

## Why it looked promising

The distinction is extremely natural for agents: reading/searching/checking is different from sending/deleting/purchasing, and reversible actions should support exploration before commitment.

## Decisive kill evidence

2026 agent work directly studies when LLM agents should act versus abstain under irreversible-action risk. `Revisable by Design` formalizes Idempotent/Reversible/Compensable/Irreversible action classes. Contemporary mechanistic work further reports causal circuit-breakers / authorization directions that generalize across irreversible agent actions and architectures. Exploration-versus-exploitation is also already an explicit LLM-agent evaluation object.

Thus both the reversibility semantic object and its mechanistic control direction are crowded. A new hidden action-status vector would not provide a wide N2 delta.

## Strongest-neighbor warning

Do not revive as irreversible-action direction, safe-exploration state, epistemic-vs-world-changing tool vector, or authorization steering by merely changing tools/tasks.

## Death code

`F2 / N0-N1-N2 — direct behavioral, formal, and mechanistic occupancy.`

## Resurrection condition

Only a genuinely different action property with an independent scientific question and unoccupied causal object could reopen this area.
