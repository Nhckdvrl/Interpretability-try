# Rejected Candidate Log 001

**Scope:** 纸面上曾经值得认真考虑，但随后被行为证据、公开 artifact、或近期文献 collision 明确砍掉/降级的可解释性候选。  
**Capacity:** 每个文档最多 10 条。  
**Updated:** 2026-08-26

> 这个目录不是“随手想过但觉得一般”的垃圾桶。只有一开始确实具备自然问题、行为基础或机制潜力，后来又被硬证据判死的题才进入。目的不是留恋旧题，而是防止后续搜题重复踩同一种坑。

## Death-code vocabulary

- `NO_NATURAL_BEHAVIOR`：自然数据上目标 failure 太少/不存在。
- `DIRECT_MECHANISM_COLLISION`：近期工作已经用基本相同的 decisive contrast + causal/mechanistic analysis 回答核心问题。
- `NARRATIVE_COLLISION`：局部组件未完全重复，但 mother question 与可写的 headline package 已被邻近工作挤压得不值得继续。
- `ARTIFACT_FAILURE`：关键数据/输出/配对 artifact 不公开或不足以支持 cheap G0。
- `NATURALNESS_FAILURE`：机制能拆，但外部问题不自然，需要解释很久才知道在研究什么。
- `METHOD_COLLISION`：即使机制尚有空间，机制导出的方法已经被更直接工作覆盖。

# 1. Role-value binding in structured generation

**Natural question:** 模型明明拿到了正确的两个值，为什么会把它们填进错误的语义槽位？

**Why it initially looked good:**

- BFCL 有公开数据、字段级 ground truth、公开模型输出；
- 可以自然区分 extraction / role understanding / binding / serialization；
- 如果自然 swap failure 足够多，机制和方法口都很清楚。

**Kill evidence:**

BFCL V4 `simple_python` 公共预检中，174 个 eligible 样本上：

- Qwen3-4B strict natural binding failures: `0 / 174`
- Gemma3-4B strict natural binding failures: `0 / 174`

目标 mother phenomenon 在冻结的自然 G0 中没有证据。

**Death code:** `NO_NATURAL_BEHAVIOR`

**Do not revive by:** 合成 origin/destination swap、换更弱模型、去更复杂 benchmark 捞几个例子、行为失败后继续 probe/SAE。

**Record:** `archive/001_role_value_binding/README.md`

# 2. Facts-vs-shortcuts arbitration in entity comparison

**Natural question:** 模型自己知道两个实体的数值，为什么比较时仍然选择由 popularity / order / co-occurrence shortcut 支持的错误答案？

**Why it initially looked good:**

- EACL 2026 已明确报告 pointwise numerical knowledge 与 pairwise decision 的自然不一致；
- 可以区分 factual activation / comparison computation / late arbitration；
- 原作者代码公开，behavior G0 成本低。

**Kill evidence:**

纸面 audit 后发现可写空间被多篇工作持续挤压：

1. EACL 2026 已做 facts-vs-shortcuts 的核心行为、shortcut factors、scale effect；
2. NAACL 2025 *The Geometry of Numerical Reasoning* 已找到实体数值属性低维表示，并做因果 intervention；
3. EACL 2026 *LLMs Know More About Numbers than They Can Say* 已做 hidden-state numerical knowledge vs wrong verbalized comparison；
4. 2026 training-dynamics 工作又覆盖 shortcut → correct-comparison strategy transition。

最后剩下的 inference-time arbitration 虽非完全重复，但 narrative package 太窄，容易变成已有工作的拼接。

**Death code:** `NARRATIVE_COLLISION`

**Do not revive by:** 换模型/语言/属性，或者把“late arbitration”单独包装成 novelty。

**Record:** `archive/002_facts_vs_shortcuts_arbitration/README.md`

# 3. Fan effect / associative-memory competition

**Natural question:** 关于同一个实体知道的事情越多，为什么其中一条反而越难取出来？

**Why it initially looked good:**

- CoNLL 2024 已直接复现 LLM fan effect；
- 可以自然区分 binding dilution、retrieval competition、late uncertainty；
- 现象老、直觉强，不依赖新 benchmark 才成立。

**Kill evidence:**

2026 机制空间迅速被占据：

- *In-context superposition: human-like working memory interference in large language models* 已发现多个 memory item 以重叠表示共存、逐层分离 target/competitors，分离程度预测 retrieval，且 selective suppression 可改善表现： https://arxiv.org/abs/2604.09670
- ACL 2026 *Cell-Based Representation of Relational Binding in Language Models* 已给出 entity–relation–attribute binding 的低维表示，并通过 activation patching 提供因果证据： https://aclanthology.org/2026.acl-long.2194/
- 原始 fan-effect behavior： https://aclanthology.org/2024.conll-1.24/

我们原计划的 decisive contrast `binding intact vs retrieval competition` 已被邻近机制工作逼得过近，继续很容易变成“把已有 working-memory interference mechanism 换到 fan-effect 数据上”。

**Death code:** `DIRECT_MECHANISM_COLLISION`

**Do not revive by:** 只强调 fan-effect 这个心理学名字不同。

# 4. Vision evidence overridden by misleading text

**Natural question:** 模型明明看见图片里是什么，为什么别人用一句冲突文字就能让它不信自己的眼睛？

**Why it initially looked good:**

- 多模态冲突行为非常自然；
- 可以区分 visual encoding failure / cross-modal arbitration / late language override；
- 适合 activation patching 和跨模态 causal tracing。

**Kill evidence:**

2026 已有非常直接的 causal mechanism 工作：

*Vision-Default, Prior-Override: Causal Mechanisms of Perception-Knowledge Conflict in Vision-Language Models* 使用 residual-stream、attention-head、MLP activation patching 与 ablation，跨三个 VLM 家族定位 prior-grounding 所依赖的少量后半层 attention heads，并区分 routing heads / writing heads；消融可在 68–96% prior-grounded cases 上翻回视觉答案。

Paper: https://arxiv.org/abs/2606.28273

这已经实质回答了“视觉看对但为何被非视觉 prior 覆盖”的 causal pathway。即使 misleading-text setup 与 parametric-prior setup 不完全相同，继续做极易退化为同一机制换 stimulus。

**Death code:** `DIRECT_MECHANISM_COLLISION`

**Do not revive by:** 把 parametric prior 换成输入文字就声称新 mother question。

# 5. Why models protect / fail to correct their own answers

**Natural question:** 为什么同一句错误答案，只要模型觉得“这是我自己刚才说的”，它就比面对别人说的同一句话更不愿改？

**Why it initially looked good:**

- self-vs-other contrast 一句话就懂；
- byte-identical content 理论上可形成极干净的 causal pair；
- 可以区分 authorship representation / confidence commitment / late role-dependent readout。

**Kill evidence:**

2026-06 的 *The Self-Correction Illusion: LLMs Correct Others but Not Themselves* 已把错误 claim 保持 byte-identical，只改变 chat-template role：`<thought>` / user / tool / memory。跨 7 个模型家族、3 个领域，外部 role 相对 self-thought 的纠错率提升 23–93 个百分点；论文进一步做了 mechanism decomposition，并给出纯 prompt-structure repair。

Paper: https://arxiv.org/abs/2606.05976

因此“self-answer commitment 是不是能力缺陷，还是 role/channel artifact”这个 decisive contrast 已被直接打中。

**Death code:** `DIRECT_MECHANISM_COLLISION`

**Do not revive by:** 换成“choice-supportive bias”“own answer bias”重新命名。

# 6. Irrelevant-tool invocation / structural matching

**Natural question:** 工具明明和用户目标无关，为什么只要参数看起来刚好能填进去，模型就忍不住调用？

**Why it initially looked good:**

- agent/tool-use 场景自然；
- 可区分 semantic relevance checking vs schema/argument matching；
- 有明确的 mechanism → routing repair 方法口。

**Kill evidence:**

ACL 2026 Main *Do LLMs Know Tool Irrelevance? Demystifying Structural Alignment Bias in Tool Invocations* 已经：

- 定义并系统验证 structural alignment bias；
- 用 SABEval 解耦 semantic relevance 与 structural alignment；
- 用 Contrastive Attention Attribution 找到 semantic-checking 与 structural-matching 两条竞争 pathway；
- 通过 pathway rebalancing 缓解错误调用；
- 代码、数据、mechanistic analysis 均公开。

Paper: https://aclanthology.org/2026.acl-long.1473/  
Code: https://github.com/along-l/irrelevant-tool

这几乎就是完整的 behavior → competing pathways → causal mechanism → mitigation package。

**Death code:** `DIRECT_MECHANISM_COLLISION`

# 7. Irrelevant-context distraction

**Natural question:** 模型明明知道一段信息和问题无关，为什么它还是会被这段话带偏？

**Why it initially looked good:**

- 极自然且广泛；
- success/failure matched pairs 易构造；
- 可区分 irrelevant-token copying、semantic class cue、reasoning-path diversion。

**Kill evidence:**

多个机制工作已经覆盖核心空间：

- ACL 2025 Outstanding Paper *Llama See, Llama Do* 发现 contextual entrainment，并定位 causally relevant entrainment heads，关闭这些 heads 会显著削弱 distraction： https://aclanthology.org/2025.acl-long.791/
- ACL 2025 *Stochastic Chameleons* 在 39 类 factual recall 上发现 class-based misgeneralization，并给出 query-based vs contextual-cue 两条竞争 circuit： https://aclanthology.org/2025.acl-long.1458/
- Findings ACL 2026 *The Mechanics of Interference* 已用 SAE counterfactual intervention 在 RAG distractor vulnerable samples 上做 targeted latent repair： https://aclanthology.org/2026.findings-acl.583/

泛化的“为什么无关信息会干扰”已不再是空 mother question。

**Death code:** `DIRECT_MECHANISM_COLLISION`

**Do not revive by:** 换成另一个 benchmark 的 distractor、另一个领域或更长 context。

# 8. Negation failure

**Natural question:** 模型明明理解一个概念，为什么前面加个“不是/不”以后就容易把逻辑搞错？

**Why it initially looked good:**

- 极自然、稳定；
- suppression vs constructive representation 是非常明确的 competing mechanisms；
- 可以直接因果干预。

**Kill evidence:**

2026-05 *How Language Models Process Negation* 已明确提出并裁决两个机制：

- suppression：抑制被否定概念；
- constructive negation：直接构造整个 negative phrase 的表示。

论文在 Mistral-7B / Llama-3.1-8B 上结合 observational + causal interpretability，发现两种机制都存在、constructive 更突出；同时指出错误主要由 late-layer attention shortcuts 导致，消融相关模块可显著改善 negation QA。

Paper: https://arxiv.org/abs/2605.03052

**Death code:** `DIRECT_MECHANISM_COLLISION`

# 9. Sycophancy / conformity as social signal override

**Natural question:** 模型明明知道正确答案，为什么别人强烈表示“大家都认为另一个答案”时，它会跟着改口？

**Why it initially looked good:**

- “知道但被社会信号压过”非常自然；
- 可以区分 knowledge loss / social-cue arbitration / late compliance；
- 机制不同可导向不同 anti-sycophancy repair。

**Kill evidence:**

2026 的 *Human-like Social Compliance in Large Language Models: Unifying Sycophancy and Conformity through Signal Competition Dynamics* 已把 sycophancy 与 conformity 放入同一机制框架，报告 convergent compliance subspace，并把转向 compliance 描述为 social/emotional signal 与 information-calibration signal 的竞争。

Paper: https://arxiv.org/abs/2601.11563

即使该工作未覆盖所有因果技术，mother narrative `internal knowledge vs external social cue competition` 已被非常直接地占据；继续做容易只剩换 benchmark / 更强 patching。

**Death code:** `NARRATIVE_COLLISION`

# 10. Overthinking in reasoning models

**Natural question:** 一道题模型其实早就会做，为什么还要继续验证、绕圈，甚至越想越错？

**Why it initially looked good:**

- 很自然，现实推理成本直接相关；
- 可区分 over-exploration / over-verification / inability-to-stop；
- 很容易导出 inference-time intervention。

**Kill evidence:**

机制与方法空间已经拥挤。NeurIPS 2025 *Mitigating Overthinking in Large Reasoning Models via Manifold Steering* 已从 mechanistic interpretability 角度发现 overthinking activation direction，进一步发现其落在低维 activation manifold，并通过 manifold steering 在 DeepSeek-R1 distilled models 上减少最多 71% 输出 token，同时维持/改善准确率。

Paper: https://papers.nips.cc/paper_files/paper/2025/hash/946827aadb9f7dbdb27f4a0c77dd1859-Abstract-Conference.html  
Preprint: https://arxiv.org/abs/2505.22411

因此再做“找 overthinking state / steering it away”基本直接 collision。除非出现一个新的、非常具体且独立存在的 behavioral phenomenon，否则不再从泛 overthinking 切入。

**Death code:** `DIRECT_MECHANISM_COLLISION`

# Cross-candidate lessons from this batch

这 10 条里最常见的死法不是“题完全没意义”，而是两类：

1. **自然现象没有先验证**：典型是 Role-Value Binding。纸面机制再漂亮，没有自然 failure 就必须停。
2. **行为论文后补机制已经来不及**：Fan effect、VLM conflict、self-correction、tool irrelevance、irrelevant context、negation、overthinking 都说明 2026 的 mechanistic work 推进很快。发现一个行为论文后，必须第一时间搜 exact causal follow-up，而不是先兴奋地设计 probe/patching。

后续搜题时，只要候选与本页任一 mother question 接近，必须先解释：

> **新的 decisive contrast 到底是什么？为什么不是换数据/换模型/换名字？**

回答不出来，直接不进入候选池。
