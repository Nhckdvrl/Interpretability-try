## 024 — 为什么过 N0

宽泛的 `descriptive vs prescriptive` 已经被 ACL 2025 做过，`alignment makes models normative` 的行为现象也已有强 mother。因此 024 **不能**讲“首次发现两个轴”。

真正留下来的新问题是：

> **Alignment 到底把“人实际上会怎么做”的 descriptive social model 改坏了，还是这个 model 仍然存在，只是 normative signal / late readout 在输出时赢了？**

只有能裁决 `descriptive degradation vs dual retention vs late arbitration`，而且与 paired base→aligned behavioral shift 对上，才有独立 paper narrative。

## 025 — 为什么过 N0

`fictional truth vs empirical truth` 已被 Truthfulness Spectrum 做掉；`context changes truth vectors` 也已被 ACL 2026 做掉。

025 只研究更窄但更基础的对象：

> **同一个 proposition，在 actual world 与一个明确 stipulated local world 下 truth value 不同时，模型是否把 truth 绑定到 world index，而不是简单让 context 覆盖 parametric truth？**

因此必须坚持 same proposition / same context / query-world swap。退化成 fictional-vs-factual probe 或 context-vs-memory conflict 就直接 ROUTE。
