## 新 ACTIVE 的最低条件

一个 fresh project 进入 `active/` 前必须已经满足：

```text
PAPER-SCALE natural question
→ benchmark-removal test
→ independent scientific object
→ concept-level novelty delta
→ 3 strong venue comparators
→ legitimate substrate
→ story invariance under competing outcomes
→ S0 / N0 / N1 / N2
→ PASS-REGISTER
```

**ACTIVE 不是“这个实验值得试”，而是“这个问题本身已经值得一篇论文，并且我们已有稳定的实验合同去回答它”。**
