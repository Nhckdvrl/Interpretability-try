# 006 D0 result index

**Evidence class:** discovery / exploratory
**Anchor model:** `Qwen/Qwen2.5-14B-Instruct`
**Canonical intervention implementation:** BF16 model with batch-local, identical-shape baseline and counterfactual forwards

## Safe current result

In the selected explicit-belief bridge surface, replacing the complete fixed-width number span in early layers is sufficient to transfer semantic action. The efficacy of replacing that source span decays over layers 16–24 and is approximately zero after layer 25, while the literal serialized value remains decodable at the source.

This result does not yet prove:

- that causal information is distributed over all eight number tokens;
- that an abstract, format-invariant posterior is represented;
- that a downstream receiver or transport path has been localized;
- that direct prompts form the same state and fail to route it.

## Important sampling/statistical limitations

- The 12 crossing pairs were deterministically selected after requiring baseline-correct bridge behavior and some pairs share donors.
- The stored bootstrap interval resamples these pairs; it is not an evidence-family population interval.
- The current non-crossing controls are not matched to crossing pairs on posterior/log-odds intervention distance (`mean raw Δp ≈ .285` versus `.645`).
- Each threshold has only four crossing pairs, so coverage of three thresholds/two mappings is not an invariance claim.
- The irrelevant-number prompt is not topology matched to the bridge prompt.
- All current layer selection and probe maxima are exploratory scans.
