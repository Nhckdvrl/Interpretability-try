# Final Verdict — 021 Task-Switch Carryover

**Status:** `ARCHIVED / MOTHER-SUBPROBLEM / INSUFFICIENT INDEPENDENT NARRATIVE`

This project was registered before the Natural-Question Reset and no model call is used to decide this archive.

The established mother literature already shows robust LLM task-switch interference. The proposed refinement — errors immediately after a switch being biased toward the old task mapping — is a useful diagnostic signature, but it does not create a sufficiently independent natural scientific object for this repository's current standard.

The project was also originally motivated by a mechanism decomposition (`Task Recognition` vs `Task Learning` heads). Under the new rules that is backwards: a hidden-state decomposition cannot be the reason a new phenomenon exists.

A future task-switch project would need a stronger mother-level question that is interesting before mentioning TR/TL heads and whose answer changes our understanding of what a task representation is, not merely where switch cost is localized.
