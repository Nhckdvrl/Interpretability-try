# 039 — Same Kind or Go Together? Taxonomic vs Thematic Semantic Relations

Status: **KILL-NOVELTY / ARCHIVED / GPU NOT AUTHORIZED**  
Originally registered: 2026-09-01  
Deregistered: 2026-09-01 after deeper N2 audit

## Former question

> Does an LLM represent **same kind / taxonomic similarity** and **go together in an event/scenario / thematic relatedness** as different, causally usable semantic relations rather than one generic notion of relatedness?

The question is natural and the Landrigan–Mirman 659-pair dual-rated human substrate is real. The project was nevertheless deregistered because a deeper strongest-neighbor audit showed that the scientific object is already occupied broadly enough that the remaining delta is mainly stronger causal MI.

## Fatal novelty collision

Three neighboring lines jointly close the Route-C novelty gap:

1. **Xiao, Wang, Álvarez & Breitling (2026), `Disentangling Similarity and Relatedness in Topic Models`, arXiv:2603.10619.** It explicitly formalizes taxonomic similarity vs thematic relatedness, uses the same TxThmNorms 659-pair human benchmark, evaluates BERT/OpenAI embedding representations on both axes, and has modern LLMs including Qwen-Turbo score the two dimensions.
2. **Xiao et al. (CoNLL 2025), `Human-likeness of LLMs in the Mental Lexicon`.** It studies Llama-3.1 lexical-semantic relatedness representations and explicitly treats semantic relatedness as encompassing taxonomic and thematic relations.
3. **Zhang et al. (2026), `A Multi-Factor Evaluation of Fidelity in LLM-Based Cross-Cultural Surrogates`.** It tests LLMs including LLaMA and Qwen on taxonomic–thematic forced choice and contains an explicit analysis of `Taxonomic versus Thematic Reasoning in LLM Explanations`.

Therefore the former proposed contribution:

```text
existing taxonomic/thematic LLM behavior + representation
→ hidden-state factorization
→ steering / causal transfer
```

fails `FINDING_RULES.md` v2.1 N2. A method upgrade from behavioral/representational evidence to causal MI is not enough when the scientific axis itself is already owned.
