# S0 gate review — 035 Shared Dynamic Context Update

Date: 2026-09-04  
Historical gate verdict: **ONE DECISIVE BEHAVIORAL VALIDATION BEFORE KEEP/ARCHIVE**  
Superseded outcome: **ARCHIVED; see `FINAL_VERDICT.md`**

## Scientific reason

The venue-scale claim requires two independently alive phenomena and a cross-phenomenon
causal-transfer denominator. The exact shared Llama checkpoint does not provide that
denominator:

- donkey-conditional anaphora binary accuracy is saturated at 0.977, although its continuous
  effect remains readable;
- released presupposition ratings have only a 0.479 high-low difference and are nonmonotone;
- the deterministic, judge-free 90-item readout predicts `high` for every item after all six
  label mappings, giving balanced accuracy 0.333 and high-vs-low accuracy 0.500;
- raw semantic predictions are not stable across label mappings.

Therefore a null cross-task patch currently cannot distinguish separate mechanisms from an
inactive or invalid presupposition recipient. However, the failed readout asks for a
three-level class decision over a phenomenon whose source evidence is graded. Before killing
the broad topic, one independently frozen binary support test over the full high/low inventory,
with all label orders and a second model family, is warranted. It is a measurement audit, not
item or layer search.

## Venue-level disposition

The natural question is broad enough for ACL/EMNLP/NAACL. It will be kept only if the binary
test supplies a nontrivial presupposition recipient in at least one analyzable checkpoint and
the effect transfers to the second family without class/label collapse. If it fails, the
required new behavior program is too large for 035 and the project will be archived. If it
passes, the next experiment remains shared cross-phenomenon causal transfer, not a standalone
presupposition classifier.

## Story-invariance guard

The current failure does **not** conclude that anaphora and presupposition use separate
mechanisms. Do not redirect it into:

- anaphora layer localization;
- a presupposition classifier paper;
- a selected lexical/template subset;
- a generic discourse-state probe without causal cross-task transfer.

All stimuli, configs, raw outputs, deterministic analyses, provenance, and experiment notes
remain retained during the decisive validation.
